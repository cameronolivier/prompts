# MOHARA Values

| Code | Shorthand | Description | Engineering examples |
|---|---|---|---|
| `MO_PRO` | Professional Expertise | We are experts in what we do. We bring technical excellence, deep domain knowledge, and consistently strong execution. | Writing quality code we can be proud of; following the F7A Engineering Rituals; building a broad base of technical knowledge while deepening a chosen niche; taking responsibility for project delivery; incorporating product thinking into everything we do |
| `MO_GRO` | Growth & Vision | We think beyond the immediate, driving sustainable growth, innovation, and long-term success for ourselves and our clients. | Considering functionality, maintainability, performance, security and scalability in everything we do; minimising technical debt; using the cutting (but not bleeding) edge of technology; supporting the growth team in winning the right projects |
| `MO_FLO` | Reliability & Process | We build strong processes ensuring consistent delivery, risk management, and operational excellence. | Embracing agile ways of working; highlighting key risks to an engagement; providing realistic estimates; following company/project processes and keeping admin up-to-date |
| `MO_ANA` | Bravery, Curiosity, Empathy | We stay bold enough to challenge old ways, curious enough to seek better ones, and empathetic enough to build with people in mind. | Using AI tools to accelerate workflows; working closely with team members and customers; using a continuous improvement mindset to evolve ways of working; asking questions to increase knowledge and understanding; supporting colleagues when things are hard |

Attach however many values genuinely apply — no cap (there are only 4 to choose from anyway). Most admirations show 1-4.
